\section{概览}

Hypoxanthine-LaTeX 是一个模块化、偏工程化维护的个人 LaTeX 生态。

\begin{itemize}
\item \HypoBF{Classes}：对外入口与场景封装（\HypoTT{Hypo-Note} / \HypoTT{Hypo-Sheet}）。
\item \HypoBF{Core}：原子能力（Fonts / Colors / Base / Math）。
\item \HypoBF{Modules}：按需插件（Box / Refs / Code / \dots）。
\end{itemize}

对外接口以 \HypoTT{FEATURES.md} 为事实来源；本手册提供更结构化的解释与可运行示例。

\section{快速上手}

在你的文档里，按\HypoIT{包名}加载入口包：

\begin{verbatim}
\documentclass{article}
\usepackage[outputdir=build]{Hypo-Note}

\begin{document}
Hello.
\end{document}
\end{verbatim}

如果你使用本仓库提供的 Makefile 模板进行构建，它会注入 \HypoTT{TEXINPUTS}，从而让
\HypoTT{\HypoBS usepackage\{Hypo-Note\}} 能直接解析到本地的 \HypoTT{sty/} 目录。

\section{入口（Classes）}

\subsection{Hypo-Note}

\HypoTT{Hypo-Note} 是“笔记型”入口（更偏阅读舒适）。它会加载 core 能力，并按选项加载 modules。

\subsection{Hypo-Sheet}

\HypoTT{Hypo-Sheet} 是“讲义/小抄型”入口（更偏紧凑排版）。当前阶段它与 \HypoTT{Hypo-Note} 共用相同的对外选项，并加载相同的 core/modules。

\section{全局选项}

两个入口共同支持以下选项：

\begin{itemize}
\item \HypoTT{indent=true/false}：段首是否缩进。
\item \HypoTT{shorthand=true/false}：数学/文本速写命令（默认开启）。
\item \HypoTT{boxes=true/false}：是否加载 Box 环境（默认开启）。
\item \HypoTT{refs=true/false}：是否加载引用模块（hyperref + cleveref，默认开启）。
\item \HypoTT{outputdir=\dots}：由 Base 导出为 \HypoTT{\HypoBS FinalOutputDir}，供需要输出目录的模块使用。
\end{itemize}

示例：

\begin{verbatim}
\usepackage[shorthand=false,boxes=false,refs=false,outputdir=build]{Hypo-Note}
\end{verbatim}

\section{Core}

\subsection{Fonts}

字体配置基于 XeLaTeX，并通过 \HypoTT{xeCJK} 处理中日韩字体。

\subsection{Colors}

工程配色定义在 \HypoTT{Hypo-Colors}。例如：

\begin{verbatim}
{\color{HypoBlueDark}Text}
\end{verbatim}

\subsection{Base（输出目录）}

Base 会导出最终输出目录宏：\quad \HypoTT{\HypoBS FinalOutputDir = \FinalOutputDir}。

\subsection{Math 与速写}

速写默认开启。常用命令包括：

\begin{itemize}
\item 文本：\HypoTT{\HypoBS TX\{\dots\}}，\HypoTT{\HypoBS TBF\{\dots\}}
\item 数学：\HypoTT{\HypoBS MB\{\dots\}}，\HypoTT{\HypoBS MC\{\dots\}}，\HypoTT{\HypoBS BS\{\dots\}}
\item 分隔符：\HypoTT{\HypoBS Abs\{\dots\}}
\end{itemize}

演示：
\[
\MB{x} + \MC{F}(\BS{\theta})\quad\mathrm{and}\quad \Abs{-3}=3.
\]

\section{Boxes（模块：Hypo-Box）}

当 \HypoTT{boxes=true}（默认）时，会提供以下环境：\HypoTT{definition}、\HypoTT{example}、\HypoTT{note}。

\subsection{标题与显式 label}

所有 box 环境均接受两个必选参数：\HypoTT{title} 与 \HypoTT{label}。

\begin{verbatim}
\begin{definition}{Title}{label}
    ...
\end{definition}
\end{verbatim}

实际写入的 label 会自动带前缀：

\begin{itemize}
\item definition：\HypoTT{def:}（例如 \HypoTT{def:group}）
\item example：\HypoTT{ex:}（例如 \HypoTT{ex:integers}）
\item note：\HypoTT{note:}（例如 \HypoTT{note:tips}）
\end{itemize}

如果你不需要引用，可以将第二个参数传空 \HypoTT{\{\}}。

\subsection{编号策略（进阶）}

Box 模块支持 \HypoTT{numbering=none/global/section/chapter}（默认 \HypoTT{section}）。

如果你想控制该选项，建议在入口里关闭 box，然后手动加载 \HypoTT{Hypo-Box}：

\begin{verbatim}
\usepackage[boxes=false]{Hypo-Note}
\usepackage[numbering=global]{Hypo-Box}
\end{verbatim}

\subsection{样式覆盖}

可通过 tcolorbox 的 hook 覆盖样式。为避免源文件出现 \HypoTT{\HypoBS tcbset} 这种以 \HypoBS t 开头的命令，这里用展示写法：

\begin{verbatim}
\tcbset{hypo definition box/.style={colframe=HypoRedDark,colback=HypoRedLight}}
\end{verbatim}

\subsection{示例}

\begin{definition}{Group}{group}
\quad A group is a set with an operation satisfying closure, associativity, identity and inverse.
\end{definition}

\begin{example}{Integers}{integers}
\quad $(\mathbb{Z}, +)$ is a group.
\end{example}

\begin{note}{Tip}{}
\quad 如果不需要引用，请将 label 留空。
\end{note}

\section{引用（模块：Hypo-Refs）}

当 \HypoTT{refs=true}（默认）时，会加载 \HypoTT{hyperref} 与 \HypoTT{cleveref}。
使用 \HypoTT{\HypoBS cref\{\dots\}} 可以得到带类型名的引用，例如：

\begin{verbatim}
See \cref{def:group}.
\end{verbatim}

本项目默认输出形如 \HypoTT{"Definition: 0.1"}、\HypoTT{"Example: 0.1"}、\HypoTT{"Note: 0.1"}。

\section{算法（模块：Hypo-Algorithm）}

当入口选项 \HypoTT{algorithm=true}（默认）时，会加载 \HypoTT{algorithm2e}。

示例：
\begin{verbatim}
\begin{algorithm}[htbp]
    \caption{Demo algorithm}
    \label{alg:demo}
    \KwIn{Input $x$}
    \KwOut{Output $y$}
    $y \leftarrow x$
\end{algorithm}

See \cref{alg:demo}.
\end{verbatim}

\section{图片插入（Core：Hypo-Img）}

\HypoTT{\HypoBS img} 是插入图片的快捷命令，默认使用 \HypoTT{figure} 环境且 placement 为 \HypoTT{htbp}，宽度默认为当前栏的 \HypoTT{0.95\\linewidth}。

\subsection{基础用法}
\begin{verbatim}
\img{path/to/image}{Caption}
\end{verbatim}

\subsection{带引用（用户只写 xxx，自动加 fig: 前缀）}
\begin{verbatim}
\img[label=demo]{path/to/image}{Caption}
See \cref{fig:demo}.
\end{verbatim}

\subsection{双栏浮动体（figure*）}
\begin{verbatim}
\img[span=2,label=wide]{path/to/image}{Wide figure}
\end{verbatim}

\section{计划中的功能}

部分接口在 \HypoTT{FEATURES.md} 中预留但尚未实现，例如：自动 label slug（尤其是中文标题）、更细粒度的缩进策略、聚合入口包（如 Hypo-All）等。

\section{代码（模块：Hypo-Code）}

当入口选项 \HypoTT{code=true}（默认）时，会加载代码模块。该模块会优先使用 \HypoTT{minted}；如果环境不支持（例如未开启 \HypoTT{-shell-escape}、未安装 minted，或缺少 Pygments），则会自动 fallback 到 \HypoTT{listings} 并给出一次性 Warning。

\subsection{基础用法}
对外推荐使用环境 \HypoTT{hypocode}：
\begin{verbatim}
\begin{hypocode}{python}
def add(a, b):
    return a + b
\end{hypocode}
\end{verbatim}

\subsection{语言支持}
\begin{itemize}
    \item minted 路径：理论上支持 Pygments 提供的全部 lexer（如 python/c++/rust/go/js/ts/java/latex/bash 等），以你本机的 Pygments 版本为准。
    \item listings fallback：内置映射支持 \HypoTT{python/py}、\HypoTT{cpp/c++}、\HypoTT{latex/tex}、\HypoTT{bash/sh}；其他语言名会原样交给 listings，若未定义则可能报错。
\end{itemize}

\subsection{常用配置接口（跨后端稳定）}
\begin{verbatim}
% 1) 是否显示行号（默认 true）
\begin{hypocode}[linenos=false]{python}
print("hello")
\end{hypocode}

% 2) 主题（仅对 minted 生效；fallback 下会被忽略）
\begin{hypocode}[theme=monokai]{python}
print("monokai")
\end{hypocode}

% 3) 后端透传（需要更细的 minted/listings 原生选项时）
\begin{hypocode}[minted={tabsize=2}]{python}
print("minted tabsize")
\end{hypocode}

\begin{hypocode}[listings={tabsize=2}]{python}
print("listings tabsize")
\end{hypocode}
\end{verbatim}

\subsection{如何启用 minted（推荐）}
minted 需要编译时开启 \HypoTT{-shell-escape} 并保证 \HypoTT{pygmentize} 可用。
在本仓库的 Makefile 体系里，可以用 \HypoTT{SHELL_ESCAPE=1} 打开（见 \HypoTT{make/Hypoxanthine.mk}）。
