\chapter{概览 (Overview)}

\HypoBF{Hypoxanthine} 是一套模块化的 \LaTeX{} 架构，旨在通过分层设计解决“笔记”、“作弊纸 (Cheatsheet)”和“文学排版”等多场景需求。

本文档全面记录了截至当前版本已实现的功能接口。本文档本身即使用 \HypoCls{Hypo-Note} 编写，是架构能力的直接演示。

\begin{note}{关于本文档}{about}
    本文档仅记录“真值”——即代码中已经跑通并可用的逻辑。不包含任何未实现的规划或愿景。
\end{note}

\chapter{快速上手 (Quick Start)}

本节给出一个\HypoBF{最推荐}的工作流：把本仓库作为子目录（或 git submodule）放入你的项目，然后用本仓库提供的 Makefile 体系构建。

\section{以子模块/子目录方式引入}

\subsection{git submodule（推荐）}
\begin{hypocode}[linenos=false]{bash}
git submodule add git@github.com:HypoxanthineOvO/Hypoxanthine-LaTeX.git Hypoxanthine-LaTeX
git submodule update --init --recursive
\end{hypocode}

\subsection{普通 clone（也可）}
\begin{hypocode}[linenos=false]{bash}
git clone git@github.com:HypoxanthineOvO/Hypoxanthine-LaTeX.git
\end{hypocode}

\section{用脚本生成模板（推荐）}

脚本位于 \HypoCode{scripts/hypo.py}，用于\HypoBF{自检}、\HypoBF{生成模板}、\HypoBF{安装 VS Code snippets}。

\subsection{依赖自检}
\begin{hypocode}[linenos=false]{bash}
python3 Hypoxanthine-LaTeX/scripts/hypo.py doctor
\end{hypocode}

\subsection{生成模板项目}
\begin{hypocode}[linenos=false]{bash}
# 生成 Hypo-Note 模板（输出到 ./demo-note）
python3 Hypoxanthine-LaTeX/scripts/hypo.py template note \
    --dest ./demo-note \
    --hypo-path ./Hypoxanthine-LaTeX \
    --with-snippets

cd ./demo-note
make
\end{hypocode}

\subsection{安装 workspace snippets（可选但强烈推荐）}
\begin{hypocode}[linenos=false]{bash}
# 安装到当前项目：./.vscode/hypoxanthine-latex.code-snippets
python3 Hypoxanthine-LaTeX/scripts/hypo.py snippets install
\end{hypocode}

\section{启用 minted（可选）}
\HypoPkg{Hypo-Code} 会优先使用 \HypoPkg{minted}；若编译时未开启 \HypoTT{-shell-escape} 或缺少 Pygments，会自动回退到 \HypoPkg{listings} 并给出 Warning。

\begin{hypocode}[linenos=false]{bash}
# Makefile 体系下开启 shell-escape（允许 minted 调用 pygmentize）
make SHELL_ESCAPE=1
\end{hypocode}

\chapter{入口类 (Entry Classes)}

Hypoxanthine 通过不同的文档类（Class）暴露给终端用户。

\section{Hypo-Note: 标准笔记}

这是最常用的入口，基于 \HypoCls{ctexbook} 构建，保留了原生 Book 的语义。

\subsection{推荐用法}
\begin{hypocode}[linenos=false]{tex}
\documentclass[outputdir=build]{Hypo-Note}
\end{hypocode}

\subsection{核心特性}
\begin{itemize}
    \item \HypoBF{基类}: \HypoCls{ctexbook}（支持 \HypoCS{chapter}, \HypoCS{part}）。
    \item \HypoBF{默认行为}: 若用户未指定，默认启用 \HypoTT{oneside} 和 \HypoTT{openany}。
    \item \HypoBF{自动加载}: 核心能力包 \HypoPkg{Hypo-Note-Core} 及图标包 \HypoPkg{Hypo-Icon}。
\end{itemize}

\subsection{类选项 (Class Options)}
以下选项可在 \HypoCS{documentclass} 中设置：

\begin{description}
    \item[\HypoTT{base=book}] 兼容性占位（若设为 \HypoTT{article} 会报错）。
    \item[\HypoTT{chapterstyle=en|cn}] 章节标题风格。默认 \HypoTT{en}。
    \item[\HypoTT{colorscheme=...}] 配色方案，支持 \HypoTT{Base}, \HypoTT{CN}, \HypoTT{Tech}, \HypoTT{Simple}。默认 \HypoTT{Base}。
    \item[\HypoTT{outputdir=<dir>}] 构建目录，默认为 \HypoTT{build}。
    \item[\HypoTT{shorthand=true|false}] 是否启用数学速写（如 \HypoCS{R}, \HypoCS{Set}）。默认 \HypoTT{true}。
    \item[\HypoTT{code=true|false}] 是否加载代码高亮模块。默认 \HypoTT{true}。
    \item[\HypoTT{boxes=true|false}] 是否加载定理盒子模块。默认 \HypoTT{true}。
\end{description}

\section{Hypo-CHSH: 速查小抄 (Cheatsheet)}

专为紧凑型打印内容设计的文档类，基于 \HypoCls{ctexart} 并魔改了多栏布局。

\subsection{推荐用法}
\begin{hypocode}[linenos=false]{tex}
\documentclass{Hypo-CHSH}
\end{hypocode}

\subsection{核心特性}
\begin{itemize}
    \item \HypoBF{自动多栏}: 文档开始后自动进入多栏模式（默认 3 栏）。
    \item \HypoBF{代码适配}: 代码块在窄栏中不会溢出，且默认关闭行号以节省空间。
    \item \HypoBF{页面计算}: 基于面积和纵横比自动计算版面。
\end{itemize}

\subsection{专属选项}
\begin{description}
    \item[\HypoTT{columns=<int>}] 分栏数量，默认 \HypoTT{3}。
    \item[\HypoTT{balance=true|false}] 是否强制平衡最后一页列高。默认 \HypoTT{false}（即使用 \HypoEnv{multicols*}）。
    \item[\HypoTT{chapterbreak=none|column|page}] 章节间的换页/换栏策略。默认 \HypoTT{none}（极度紧凑）。
    \item[\HypoTT{textsize=...}] 全局字号，默认为 \HypoTT{footnotesize}。
\end{description}

\section{Hypo-LitNote: 文学笔记}

面向人文类内容的排版配置。

\subsection{核心特性}
\begin{itemize}
    \item 默认启用 \HypoTT{chapterstyle=cn}。
    \item 默认启用 \HypoTT{litbox=true}，提供诗歌、引用等文学环境。
    \item 默认 \HypoTT{sectionstyle=outline}，隐藏小节编号，避免出现“1.1”这种理科感强的序号。
\end{itemize}

\chapter{核心能力 (Core)}

所有 Class 底层均依赖于 \HypoPkg{Hypo-Note-Core} 及其原子能力包。

\section{基础能力 (Base)}

\HypoPkg{Hypo-Base} 提供了文档编写的基础设施。

\subsection{路径与导出}
通过选项 \HypoTT{outputdir} 传入的目录会被保存至宏 \HypoCS{FinalOutputDir}，供 \HypoPkg{minted} 等宏包调用。

\subsection{排版辅助命令}
专门用于编写 Manual 或 README 的语义化命令：

\begin{itemize}
    \item \HypoCS{HypoCS\{foo\}} $\rightarrow$ \HypoCS{foo} （排版控制序列）
    \item \HypoCS{HypoEnv\{name\}} $\rightarrow$ \HypoEnv{name} （排版环境名）
    \item \HypoCS{HypoPkg\{name\}} $\rightarrow$ \HypoPkg{name} （排版包名）
    \item \HypoCS{HypoCode\{...\}} $\rightarrow$ 等宽显示代码片段
\end{itemize}

\section{字体与颜色 (Fonts \& Colors)}

\subsection{字体策略}
依赖 \HypoPkg{xeCJK} 和 \HypoPkg{fontspec}。
\begin{itemize}
    \item \HypoBF{中文}: 优先 \HypoTT{LXGW WenKai}，降级至 Noto 或 Fandol。
    \item \HypoBF{英文}: 优先 \HypoTT{DejaVu} 系列。
\end{itemize}

\subsection{配色方案}
通过 \HypoCS{HypoColorSchemeSetup} 或 Class 选项注入。当前支持：
\begin{itemize}
    \item \HypoTT{Base}: 默认风格。
    \item \HypoTT{CN}: 中国传统色风格。
    \item \HypoTT{Tech}: 科技蓝/冷色调风格（当前文档使用）。
    \item \HypoTT{Simple}: 极简黑白/灰阶风格。
\end{itemize}

\section{数学支持 (Math)}

\HypoPkg{Hypo-Math} 预定义了常用符号。若选项 \HypoTT{shorthand=true}，则启用以下速写：

\begin{itemize}
    \item 集合: \HypoCS{R} ($\R$), \HypoCS{N} ($\N$), \HypoCS{Z} ($\Z$)
    \item 定界符: \HypoCS{Set\{x\}} $\rightarrow$ $\Set{x}$, \HypoCS{Paren\{x\}} $\rightarrow$ $\Paren{x}$
    \item 样式: \HypoCS{MB\{x\}} ($\MB{x}$), \HypoCS{MC\{x\}} ($\MC{x}$)
\end{itemize}

\chapter{功能模块 (Modules)}

模块按需加载，通常由 Class 选项控制。

\section{定理盒子 (Box)}
由 \HypoPkg{Hypo-Box} 提供，基于 \HypoPkg{tcolorbox}。

\subsection{环境签名与 label 规则}
\HypoPkg{Hypo-Box} 的盒子环境（如 \HypoEnv{definition}/\HypoEnv{example}/\HypoEnv{note}）统一采用两个\HypoBF{必选参数}：
\HypoTT{\{title\}\{label\}}。

\begin{hypocode}[linenos=false]{tex}
\begin{definition}{Title}{label}
    ...
\end{definition}
\end{hypocode}

label 会自动加前缀：
\begin{itemize}
    \item \HypoEnv{definition}：\HypoTT{def:}
    \item \HypoEnv{example}：\HypoTT{ex:}
    \item \HypoEnv{note}：\HypoTT{note:}
\end{itemize}
若你不需要引用，可以将第二个参数留空 \HypoTT{\{\}}。

\begin{definition}{定义示例}{demo_def}
    这是一个标准的定义环境。
    \begin{equation}
        E = mc^2
    \end{equation}
\end{definition}

\begin{note}{注意事项}{label-note}
    Label 会自动添加前缀。例如上面的定义 label 为 \HypoTT{demo\_def}，引用时应使用 \HypoTT{def:demo\_def}。
\end{note}

支持的环境包括：\HypoEnv{definition}, \HypoEnv{example}, \HypoEnv{note}。

\subsection{基础用法：\HypoCS{cref}}
\begin{verbatim}

\end{verbatim}

效果：See \cref{def:demo_def}.

\section{代码高亮 (Code)}
由 \HypoPkg{Hypo-Code} 提供。

\subsection{环境签名}
推荐统一使用环境 \HypoEnv{hypocode}：
\begin{itemize}
    \item 必选参数：\HypoTT{\{language\}}，例如 \HypoTT{python}/\HypoTT{tex}/\HypoTT{bash}。
    \item 可选参数：\HypoTT{[key=value,...]}。
\end{itemize}

\begin{verbatim}
\begin{hypocode}[linenos=false]{python}
def hello():
    print("Hello Hypoxanthine")
\end{hypocode}
\end{verbatim}

效果：
\begin{hypocode}[linenos=false]{python}
def hello():
    print("Hello Hypoxanthine")
\end{hypocode}

\subsection{后端与回退策略}
\begin{itemize}
    \item \HypoBF{minted 优先}: 需要编译开启 \HypoTT{-shell-escape} 且本机存在 \HypoPkg{minted} 与 Pygments（\HypoTT{pygmentize}）。
    \item \HypoBF{listings 回退}: 不满足 minted 条件时自动回退；尽量保持对外接口稳定。
\end{itemize}

\subsection{稳定选项（两种后端都可写）}
\begin{description}
    \item[\HypoTT{linenos=true|false}] 是否显示行号（默认通常为 true；在小抄类场景可能会默认关闭）。
    \item[\HypoTT{theme=<name>}] minted 主题（仅 minted 生效；listings 下会忽略）。
    \item[\HypoTT{minted=\{...\}}] 透传 minted 原生选项（仅 minted 生效）。
    \item[\HypoTT{listings=\{...\}}] 透传 listings 原生选项（仅 listings 生效）。
\end{description}

示例：
\begin{verbatim}
% 1) 关闭行号
\begin{hypocode}[linenos=false]{python}
print("no line numbers")
\end{hypocode}

% 2) minted 主题（listings 下会忽略）
\begin{hypocode}[theme=monokai]{python}
print("monokai")
\end{hypocode}

% 3) 透传后端原生参数
\begin{hypocode}[minted={tabsize=2}]{python}
print("minted tabsize")
\end{hypocode}

\begin{hypocode}[listings={tabsize=2}]{python}
print("listings tabsize")
\end{hypocode}
\end{verbatim}

\section{绘图 (Plot)}
由 \HypoPkg{Hypo-Plot} 提供。

\subsection{定位}
\HypoPkg{Hypo-Plot} 允许你在文档里直接写 Python/Matplotlib 代码，编译时自动生成图片并插入正文。
它适合：\HypoBF{论文/笔记里的快速画图}、\HypoBF{与主题色对齐的可复现图}、\HypoBF{把绘图脚本随文档一并版本化}。

\subsection{依赖与构建要求}
\begin{itemize}
    \item 需要启用 \HypoTT{-shell-escape}（Makefile 体系：\HypoCode{make SHELL_ESCAPE=1}）。
    \item 需要可用的 Python（默认 \HypoTT{python3}；可用 \HypoCS{HypoSetPythonBin} 指定）。
    \item Python 环境需要 Matplotlib（以及你在脚本中 import 的其他库，例如 numpy）。
\end{itemize}

\subsection{环境：\HypoEnv{HypoPyPlot}}
环境通过 Key-Value 参数控制输出文件名、图像尺寸与插图宽度。
其中 \HypoTT{name} 为\HypoBF{必填}：

\begin{hypocode}[linenos=false]{tex}
\begin{HypoPyPlot}[
  name=demo_sine,
  width=0.75\linewidth,
  figwidth=4.8,
  figheight=2.6,
  dpi=160,
  format=png
]
x = np.linspace(0, 2*np.pi, 256)
y = np.sin(x)
plt.plot(x, y, color=HYPO_BLUE, linewidth=2.0)
plt.grid(True, alpha=0.3)
\end{HypoPyPlot}
\end{hypocode}

说明：
\begin{itemize}
    \item \HypoTT{width/height} 传给 \HypoCS{includegraphics}，支持 \HypoCode{0.75\linewidth} 这类长度表达式。
    \item \HypoTT{centering=true|false} 控制插图是否自动居中（默认 \HypoTT{true}）。
    \item \HypoTT{figwidth/figheight} 对应 Matplotlib 的 \HypoTT{figsize}（单位 inch）。
    \item 会按 \HypoCS{FinalOutputDir} 落盘：脚本在 \HypoTT{build/scripts/}，图片在 \HypoTT{build/figures/}。
    \item 会注入主题色（如 \HypoTT{HYPO\_BLUE/HYPO\_ORANGE/...}）方便绘图配色与文档一致。
\end{itemize}

\end{itemize}
