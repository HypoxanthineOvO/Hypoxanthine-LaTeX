\chapter{介绍 (Introduction)}

\section{设计哲学}

Hypoxanthine-LaTeX 是一套\HypoBF{工程化}的 LaTeX 解决方案。传统的 LaTeX 模板往往将所有逻辑堆砌在一个 `.sty` 文件中，不仅维护困难，而且难以在不同类型的文档（如技术笔记和文学随笔）之间复用核心样式。

本架构的设计核心在于\HypoBF{关注点分离}：
\begin{itemize}
    \item \HypoBF{Classes (业务层)}: \HypoTT{Hypo-Note}, \HypoTT{Hypo-LitNote}, \HypoTT{Hypo-CHSH}。它们只负责“文档是干什么的”（页面布局、标题格式）。
    \item \HypoBF{Core (能力层)}: \HypoTT{Hypo-Fonts}, \HypoTT{Hypo-Colors}。它们负责“文档长什么样”（字体、配色），且对所有 Class 通用。
    \item \HypoBF{Modules (组件层)}: \HypoTT{Hypo-Box}, \HypoTT{Hypo-Code}, \HypoTT{Hypo-Plot}。它们是按需加载的功能插件。
\end{itemize}

这种设计使得你可以在撰写《算法导论笔记》和《唐诗三百首》时，底层共享同一套字体配置和颜色变量，而上层表现出完全不同的排版气质。

\section{适用场景}

\begin{itemize}
    \item \HypoBF{Hypo-Note}: 适用于计算机科学、数学、物理等理工科技术文档。预置了代码高亮、算法环境和严谨的定理盒子。
    \item \HypoBF{Hypo-LitNote}: 适用于人文社科、随笔、诗歌整理。预置了优美的引用块、诗歌环境，并采用更人文的字体配置。
    \item \HypoBF{Hypo-CHSH}: 适用于“作弊纸”(Cheatsheet)。采用高密度的多栏布局，尽可能在 A4 纸上容纳更多信息。
\end{itemize}

\chapter{盒子系统 (The Box System)}

盒子是 Hypoxanthine 的核心视觉组件。通过 \HypoPkg{Hypo-Box} 模块提供，基于强大的 \HypoPkg{tcolorbox}。

\section{设计意图 (Design Philosophy)}

在技术文档中，建立清晰的 \HypoBF{视觉层级 (Visual Hierarchy)} 至关重要。你需要让读者一眼区分出哪些是核心结论（定理），哪些是辅助理解（例子），哪些是避坑指南（注意）。

Hypoxanthine 摒弃了传统 LaTeX \HypoCode{\textbackslash newtheorem} 枯燥的斜体样式，采用了基于色彩心理学的 \HypoBF{全彩盒子} 设计：

\begin{itemize}
    \item \HypoBF{Primary (蓝紫系)}: 代表理性与严谨。用于 \HypoEnv{definition}, \HypoEnv{theorem}, \HypoEnv{lemma}, \HypoEnv{proposition}, \HypoEnv{corollary}。
    \item \HypoBF{Success (青绿系)}: 代表验证与实践。用于 \HypoEnv{example}。
    \item \HypoBF{Warning (橙黄系)}: 代表警示与强调。用于 \HypoEnv{note}, \HypoEnv{tip}, \HypoEnv{important}, \HypoEnv{warning}。
\end{itemize}

这种设计让读者在快速浏览时，能够迅速建立对内容的认知模型。这体现了 \HypoBF{关注点分离} 的原则：作者只需声明“这是一个定理”，而不用操心“定理应该用什么字体和边框”。

\chapter{代码与算法 (Code \& Algorithms)}

\section{设计意图 (Motivation)}

代码是现代技术文档的一等公民。烂大街的 LaTeX 默认代码样式（黑白、无衬线字体、无边框）不仅难以阅读，更破坏了文档的整体美感。

Hypoxanthine 的代码模块 (\HypoPkg{Hypo-Code}) 致力于提供 \HypoBF{IDE 级别} 的阅读体验：
\begin{enumerate}
    \item \HypoBF{美感驱动}: 默认采用柔和的背景色和圆角设计，减轻阅读疲劳。
    \item \HypoBF{语义高亮}: 区分关键字、字符串、注释，帮助读者快速解析代码逻辑。
    \item \HypoBF{鲁棒性}: 在宽窄栏切换、跨页断行、特殊字符（如 Unicode 字符）处理上做了大量适配。
\end{enumerate}

\chapter{绘图与可视化 (Plotting)}

\section{核心优势 (Why Hypo-Plot?)}

在科研写作中，绘图通常是最令人头秃的环节。传统的 "Python 绘图 $\to$ 保存 PNG $\to$ 插入 LaTeX" 流程存在三大痛点：
\begin{enumerate}
    \item \HypoBF{风格割裂}: 图片中的字体（Arial/Helvetica）与正文（Computer Modern/Times）格格不入，字号大小也难以统一。
    \item \HypoBF{维护地狱}: 一旦需要修改数据或配色，必须重新运行脚本、导出、覆盖文件。
    \item \HypoBF{矢量缺失}: 导出 PNG 会模糊，导出 PDF 又经常遇到裁剪白边的问题。
\end{enumerate}

\HypoPkg{Hypo-Plot} 通过 \HypoEnv{HypoPyPlot} 环境彻底解决了这些问题。它允许你 \HypoBF{在 LaTeX 源码中直接编写 Python 绘图代码}。

\begin{itemize}
    \item \HypoBF{自动配色}: 绘图脚本会自动读取当前文档的主题色（如 \HypoTT{HYPO\_BLUE}），确保图表颜色与文档配色方案（Tech/Lit/Base）完美融合。
    \item \HypoBF{自动字体}: 图片中的文字直接使用 LaTeX 渲染，保证与正文字体完全一致。
    \item \HypoBF{构建缓存}: 只有当代码变更时才会重新运行 Python 脚本，编译速度飞快。
\end{itemize}

\section{工作流详解 (Workflow)}

当你在文档中使用 \HypoEnv{HypoPyPlot} 环境时，发生的幕后工作流如下：

\begin{enumerate}
    \item LaTeX 编译时，将环境内的 Python 代码提取并写入文件：\HypoTT{build/scripts/name.py}。
    \item 注入模板代码：在你的代码前，会自动注入 \HypoTT{import matplotlib.pyplot as plt} 以及当前文档的配色变量（如 \HypoTT{HYPO\_BLUE}）。
    \item 调用 Python 解释器执行脚本。
    \item 脚本将图片保存为：\HypoTT{build/figures/name.png} (或 pdf)。
    \item LaTeX 使用 \HypoCS{includegraphics} 插入该图片。
\end{enumerate}

\section{TikZ 外部化 (Externalization)}

\HypoPkg{Hypo-Plot} 同时提供了对 TikZ 外部化的简化封装：\HypoCS{HypoTikZFile}。

\begin{hypocode}[linenos=false]{tex}
\HypoTikZFile[width=0.8\linewidth]{my_network}{assets/network.tikz}
\end{hypocode}

它会自动对比 \HypoTT{.tikz} 源文件的 MD5 指纹，仅在源文件变更时重新调用 \HypoTT{pdflatex} 编译该图。这对于包含大量 TikZ 图的大型文档能显著提升编译速度。

\HypoCls{Hypo-LitNote} 专为非技术文档设计。无论是为了整理诗词、撰写随笔还是排版人文社科类文章，我们都希望页面更加“透气”，字体更加具有人文关怀。

\section{文学组件 (Hypo-LitBox)}

\subsection{诗歌环境 (poem)}
背景极淡，适合摘录诗词。

\begin{hypocode}[linenos=false]{tex}
\begin{poem}[title=静夜思]
    床前明月光，\\
    疑是地上霜。
\end{poem}
\end{hypocode}

\begin{poem}[title=静夜思]
    床前明月光，\\
    疑是地上霜。
\end{poem}

\subsection{引用段落 (quotepara)}
适合摘录长段落，带有明显的左侧装饰。

\begin{hypocode}[linenos=false]{tex}
\begin{quotepara}[title=瓦尔登湖]
    我步入丛林，因为我希望活得有意义...
\end{quotepara}
\end{hypocode}

\begin{quotepara}[title=瓦尔登湖]
    我步入丛林，因为我希望活得有意义，我希望活得深刻，吸取生命中所有的精华，把非生命的一切都击溃，以免在我临终时，发现自己未曾活过。
\end{quotepara}

\subsection{行内微凸显 (InlineQuote)}
\begin{hypocode}[linenos=false]{tex}
就像 \InlineQuote{这样} 在行内轻轻强调。
\end{hypocode}
效果：\InlineQuote{行内浅底强调效果}。



\section{图像命令 (Img)}
\HypoPkg{Hypo-Img} 提供了简化的插图命令：

\begin{hypocode}[linenos=false]{tex}
\img[width=0.8\linewidth, label=myfig]{example-image}{测试图片}
\end{hypocode}

此命令会自动处理 \HypoEnv{figure} 环境、居中、Caption 和 Label（自动添加 \HypoTT{fig:} 前缀）。

效果（并演示引用）：
